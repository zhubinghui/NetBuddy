# NetBuddy

**简体中文** | [English](README.en.md)

> An AI agent that cares for your network.

NetBuddy 是一个面向网络运维场景的 AI Agent harness，可以安全&可靠的操作网络设备，也可以进行离线故障诊断，并且不断进化的智能运维工具。

## 项目状态

**早期开发中** — 架构设计讨论进行中，欢迎参与。

## 愿景

- **故障在线诊断**：在线接入网络，基于提供的网络拓扑（也支持自发现拓扑），自动采集日志分析，给出故障处理建议，human in loop 的基本思想，在得到充分授权的基础之上，可以做相应的配置调整，整体的故障定位确保可控可管，可追溯，故障定位完成之后，支持清理所有定位操作；
- **故障离线诊断**：离线提供故障相关的日志、诊断日志、拓扑等相关信息，自动进行故障根因的因果推断，给出根因或者进一步处理的建议；
- **巡检**：基于给定的网络拓扑，和期望巡检的设备，自动登录设备，并且在得到充分授权的情况下，自动巡检设备，检查设备隐患；
- **变更保障**：基于多维度的数字孪生能力，进行变更操作的风险推演，提供确定性的操作结果推演，并且支持所有操作的回退。
