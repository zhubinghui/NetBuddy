# NetCare

> An AI agent that cares for your network.

**NetCare** 是一个面向网络运维场景的 AI Agent harness，目标是让 Agent 像随队军医一样照护你的网络：巡检、诊断、修复、值守。

## 项目状态

🚧 **早期开发中** — 架构设计讨论进行中，欢迎参与。

## 愿景

- 🔍 **巡检**：自动化的网络健康检查与状态感知
- 🩺 **诊断**：基于 LLM 的故障定位与根因分析
- 🔧 **修复**：可审计、可回滚的自动化修复动作
- 🌙 **值守**：7x24 告警响应与升级
